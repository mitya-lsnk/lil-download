# lil download

[English](README.md) · **Русский**

Кроссплатформенное десктоп-приложение для сохранения видео и звука: вставляешь
ссылку — получаешь файл. YouTube, Twitter/X, Vimeo и ещё тысяча сайтов, которые знает
[yt-dlp](https://github.com/yt-dlp/yt-dlp). Ничего о вас не собирается, аккаунт не
нужен — приложение открывает только те соединения, о которых вы попросили. См.
[Что уходит в сеть](#что-уходит-в-сеть).

| **lil download** | приносить: видео и звук отовсюду, куда дотягивается yt-dlp — вы здесь |

## Установка

Готовые сборки — во [вкладке Releases](../../releases):

| | |
|---|---|
| **macOS** | `.dmg` — один универсальный файл и для Apple Silicon, и для Intel |
| **Windows** | установщик `.exe` или `.msi`, если так удобнее разворачивать |
| **Linux** | `.deb`, `.rpm` или `.AppImage` |

Подписи нет ни у той, ни у другой сборки. macOS: первый запуск — правой кнопкой по
приложению, «Открыть». Windows: SmartScreen скажет «неизвестный издатель» →
«Подробнее» → «Выполнить в любом случае».

**yt-dlp и ffmpeg внутрь не вшиты.** Приложение скачивает их при первом запуске и
держит рядом с собой. Это намеренно: yt-dlp выходит каждые пару недель вслед за
изменениями YouTube, и замороженная внутри копия сломалась бы в течение месяца. У
ffmpeg вдобавок GPL — отдельная причина не встраивать.

## Два решения, которые стоит знать

**«Лучшее качество» и «откроется везде» — разные файлы.** H.264 у YouTube
заканчивается на 1080p; выше идут VP9 и AV1, которых не берёт ни QuickTime, ни
большинство монтажек. Поэтому пресет качества и контейнер — отдельные переключатели, а
меню показывает, что именно каждый из них даст для ссылки на экране.

**Плейлист по умолчанию отрезается от ссылки.** Если вставили видео, которое просто
лежит в плейлисте, скачаться должно оно. Скачать все 92 — это кнопка, а не
случайность.

## Язык интерфейса

Интерфейс есть на **русском и английском**, переключается в шапке. Весь текст лежит в
[`src/lib/strings.tsx`](src/lib/strings.tsx) — добавьте ключ в объект `RU`, и
компилятор потребует парный `EN`, так что забытый перевод будет ошибкой сборки, а не
пустой подписью.

## Стек

- **Tauri 2** — каркас (Rust-бэкенд + системный WebView). Лёгкий, ~10 МБ рантайма.
- **React + TypeScript + Vite** — фронтенд.
- **yt-dlp** — все экстракторы, скачивается и обновляется в рантайме.
- **ffmpeg** — склейка, перекладывание в контейнер, перекодирование и обрезка, тоже
  скачивается в рантайме.

## Сборка

Нужны Node ≥ 22 и Rust.

```bash
npm install          # один раз
npm run tauri dev    # разработка
```

Собрать релиз под текущую систему:

```bash
npm run tauri build
```

Все три платформы собирает [CI](.github/workflows/build.yml) на каждый пуш, а тег
`v*` дополнительно открывает черновик релиза со всеми файлами. Кросс-сборка под
Windows с мака требует MSVC SDK, LLVM и NSIS — и всё равно даёт неподписанный
результат, который никто не запускал; матрица существует, чтобы этого не делать.

## Что уходит в сеть

Ни телеметрии, ни аналитики, ни отчётов о падениях, ни аккаунта. Приложение открывает
четыре вида соединений, и все — потому что вы попросили:

| Когда | Куда | Что уходит |
|---|---|---|
| **При запуске** — сверка версии | `api.github.com` | Только сам запрос: ваш IP и User-Agent `lil-download/<версия>`. Кэшируется на шесть часов. |
| **Вы нажали «Установить» / «Переустановить»** | GitHub Releases (yt-dlp), evermeet.cx / BtbN / johnvansickle (ffmpeg) | Только сам запрос. После первого запуска — никогда автоматически. |
| **Вы вставили ссылку на YouTube** | `i.ytimg.com` | Идентификатор видео, чтобы показать обложку до того, как вернётся опрос сайта. |
| **Вы нажали «Скачать»** | Сайт, который вы назвали, через yt-dlp | То, что отправляет ему yt-dlp — плюс ваши куки, если и только если вы выбрали браузер. |

**Куки через приложение не проходят.** Выбор браузера передаёт yt-dlp его *название*;
хранилище куки читает сам yt-dlp. Загрузчику незачем держать в руках чужие сессии.

## Как это устроено

```
lil-download/
├── src/                        # фронтенд (React)
│   ├── App.tsx                 # каркас, очередь, единственный экран
│   ├── lib/
│   │   ├── api.ts              # типизированные обёртки над командами Rust
│   │   ├── settings.ts         # настройки, правила папок, свои пресеты
│   │   ├── template.ts         # каталог из 80 полей имени, разбор и сборка
│   │   ├── predict.ts          # что даст пресет именно для этой ссылки
│   │   ├── cache.ts            # что помнится, чтобы окно рисовалось сразу
│   │   ├── thumb.ts            # обложка, выведенная из самой ссылки
│   │   ├── history.ts          # очередь, живущая между запусками
│   │   ├── i18n.tsx            # язык интерфейса (RU/EN)
│   │   ├── skin.tsx            # скин и светлая/тёмная тема
│   │   └── strings.tsx         # весь текст интерфейса, оба языка
│   └── components/
│       ├── LinkBar.tsx         # единственное поле ввода
│       ├── MediaCard.tsx       # ссылка до того, как её скачали
│       ├── Queue.tsx           # загрузки, идущие и законченные
│       ├── PresetPicker.tsx    # качество и контейнер, разведённые по разным вопросам
│       ├── PresetEditor.tsx    # пресеты, собранные руками
│       ├── TemplateBuilder.tsx # имя файла из кусочков
│       ├── FlagsInput.tsx      # флаги yt-dlp с подсказками
│       ├── CookiePicker.tsx    # у какого браузера одолжить сессию
│       ├── ToolsPanel.tsx      # yt-dlp и ffmpeg: состояние и кнопки
│       └── SettingsScreen.tsx  # программы, скачивание, пресеты, оформление
├── src-tauri/
│   └── src/
│       ├── lib.rs              # регистрация команд; тяжёлое — мимо главного потока
│       ├── urlx.rs             # разбор ссылки: плейлист отрезан, трекеры выброшены
│       ├── bins.rs             # поиск, установка и версии двух программ
│       ├── probe.rs            # метаданные и перевод ошибок yt-dlp в ответы
│       ├── dl.rs               # само скачивание: аргументы, прогресс, отмена
│       └── cookies.rs          # вердикт по доступу для каждого браузера
└── .github/workflows/build.yml # macOS · Windows · Linux
```

## Чего пока нет

- **Вшитые в картинку субтитры** требуют полного перекодирования через фильтр ffmpeg;
  средствами yt-dlp это не делается. Не сделано.
- **Именованные конфиги с экспортом** — пресеты пока живут на одной машине.
- **Поиск по настройкам** — вкладок сегодня немного, но так будет не всегда.
